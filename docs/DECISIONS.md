# Foundation decisions

This document records decisions needed to make the 0.15 foundation coherent.
Normative behavior remains in [BEHAVIOR.md](BEHAVIOR.md), package ownership in
[ARCHITECTURE.md](ARCHITECTURE.md), evidence limits in [PROVENANCE.md](PROVENANCE.md),
and surface coverage in [PARITY.md](PARITY.md).

| ID     | Decision                                                                                                                                                                   | Consequence                                                                                                                                                                | Owner link                                                             |
| ------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| `D-03` | Effect Schema from `effect/Schema` at stable `3.22.1` is the sole boundary-validation ecosystem; `@effect/schema` and alternate validators are absent.                     | Every package and process boundary shares one runtime/type validation owner.                                                                                               | [ARCHITECTURE.md](ARCHITECTURE.md), [DEPENDENCIES.md](DEPENDENCIES.md) |
| `D-04` | Schema decoding is strict at untrusted boundaries and preserves structured error identities.                                                                               | Unknown or malformed values fail before business logic or effects.                                                                                                         | [BEHAVIOR.md](BEHAVIOR.md), [SECURITY.md](SECURITY.md)                 |
| `D-06` | Mise tracks the Bun `1.4.x` line, currently resolved to `1.4.0`; TypeScript is `7.0.2`, Vite+ is `0.2.9`, and the public version is read only from the canonical manifest. | Compatibility stays on Bun 1.4 bugfix releases while the checked-in lockfile records the resolved patch.                                                                   | [PROVENANCE.md](PROVENANCE.md), [RELEASING.md](RELEASING.md)           |
| `D-07` | App Server generated artifacts are identified by the exact Codex executable digest plus a sorted path/digest manifest.                                                     | Generated protocol output is reproducible and auditable without treating a directory timestamp or order as identity.                                                       | [PROVENANCE.md](PROVENANCE.md), [PARITY.md](PARITY.md)                 |
| `D-08` | The only parity exception is babysit-ci observation after an approved push/tag, with no mutation authority.                                                                | CI observation cannot authorize or perform an external write.                                                                                                              | [PARITY.md](PARITY.md), [SECURITY.md](SECURITY.md)                     |
| `D-09` | Native four-primitive Effect workflow modules are production; QuickJS is explicit compatibility only, and Root approval precedes runtime effects.                          | Workflow source and policy stay separate from deterministic mechanics; compatibility cannot be selected implicitly, and the stable App Server fallback remains executable. | [BEHAVIOR.md](BEHAVIOR.md), [CLI.md](CLI.md)                           |
