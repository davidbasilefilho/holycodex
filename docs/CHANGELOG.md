# Changelog

## 0.12.3

`plus-low` becomes the default. Paid plans use cost-per-success-oriented Sol Root routes and stage-aware Luna specialist escalation, with Terra, Sol xhigh, and Sol max removed from default routing. Workflow policy now separates soft target calls from hard maximum calls, expresses expected usage relative to `plus-low`, preserves Standard as the default and Fast as an explicit 2× opt-in, and retains no fixed workflow-wide duration limit. Root instructions require ask-tool approval for reviewed plans and sensitive actions.

Release history is published through GitHub releases. Repository changes remain visible in Git history and version tags.
