# Integrations

HolyCodex installs no MCP servers.

Dynamic workflows use Codex App Server as the supported programmatic bridge to isolated Codex threads. The bridge passes the active sandbox and approval policy through unchanged, preserves tool and trust restrictions, streams concise lifecycle events, and uses Codex cancellation for individual agents. A non-interactive host cannot invent an approval response; an action requiring fresh approval fails closed unless the active surface can forward the prompt.

Context7 runs directly as `ctx7@latest` through nub, Bun, pnpm, npm, or Yarn. The skill retains library ID and version selection, focused queries, the two-step lookup, a three-call bound, sensitive-data exclusion, and unauthenticated project skill commands.

LSP uses a stable CLI backed by the reusable internal daemon. Structured JSON output is available with `--json`; operational failures return nonzero status and bounded diagnostics.

Native Windows uses the bundled Git Bash launcher for all task shell commands. Resolver and launcher readiness remain installation and doctor requirements.
