# TypeScript

Preserve runtime/package manager; use strict `tsc` and project formatter/linter/tests. Parse external `unknown`; prefer discriminated unions, `readonly`, `satisfies`, type-only imports, named exports. No `any`, ignored diagnostic, non-null assertion, unchecked cast, enum, empty catch, swallowed error. Expose cancellation/timeout where callers need it. React: semantic HTML, stable keys, minimal effects, derived state. Test public behavior with Vitest/project runner; run format, types, targeted tests.
