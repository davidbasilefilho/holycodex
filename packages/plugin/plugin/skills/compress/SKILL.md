# Compress

Keep facts, distinctions, exact values/order, constraints, exceptions, permissions, gates, warnings, evidence/citations, stops. Remove repetition, filler, hedging, ceremony, inflation, obvious explanation.

Preserve exact names/strings, code/commands/paths/APIs/errors/numbers/links, legal/user terms. Compare source: no loss, weaker ban, invented claim, broken reference, scope change, omitted exception/warning/validation/stop.

For prompts/instructions/skills preserve frontmatter, triggers, exclusions, routing, permissions, validation, stops. Code/config: prose only.

Preserve the surrounding voice unless the user explicitly requests a different one.
