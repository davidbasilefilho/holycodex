# Visualize

Choose a visual when it makes an explanation, comparison, pattern, relationship, or scenario easier to understand. Use the host's supported rich in-chat visualization capability when available; choose a chart, diagram, spatial view, or interactive control according to the task. A simple answer does not need a visual, and a visualization does not require building a website.

Inspect the current host's tools and rendering support, then follow their documented contract. Do not invent DIL markup or assume this skill supplies a renderer. ChatGPT web and desktop support rich visualizations; CLI and IDE surfaces do not render them. When the current host cannot render the requested form, use a supported image, artifact, or clear textual explanation and disclose any material limitation.

Preserve factual meaning, label units and uncertainty, and use controls only when they help explore the question. Verify the actual rendered result and affected interactions through available tools. Root owns visual acceptance and the inspect, review, fix, and reverify loop. This guidance does not grant host, browser, computer, or publishing permissions.

Public capability reference: https://learn.chatgpt.com/docs/visualizations
